ЗАПУСК
Сайт открывается по имени http://slime.localhost/ (без IP и без порта). Для этого скрипт просит
права администратора (нажми «Да»): имя и порт 80 без них Windows не даёт занять. Имя работает
в Chrome, Edge и Firefox. Свой адрес: -Name мой.localhost. Без имени и без администратора:
-NoName (тогда http://127.0.0.1:порт/). Если порт 80 занят, сайт сам возьмёт 8765.
Адреса сторонних API (Jikan, Shikimori, AniLibria) браузер больше не видит: он обращается к
/s/a/..., а настоящие адреса лежат только в start.ps1 ($Upstreams). Картинки персонажей, шрифты
и видеопотоки браузер по-прежнему грузит напрямую с их серверов — их адреса в браузере видно.
1. Распакуй папку, открой в ней PowerShell
   (Shift + правая кнопка в папке -> «Открыть окно PowerShell здесь»).
2. Выполни:
     powershell -ExecutionPolicy Bypass -File .\start.ps1
   Если Windows ругается на скачанный файл:  Unblock-File .\start.ps1
3. Откроется браузер. Остановить сайт: Ctrl+C в окне PowerShell.

ДОСТУП С ТЕЛЕФОНА
Запусти так:  powershell -ExecutionPolicy Bypass -File .\start.ps1 -Share
Windows спросит права администратора — нажми «Да» (откроется новое окно).
В нём будут адреса вида http://192.168.x.x:8765/ и 6-значный код. Телефон должен быть в той же
Wi-Fi сети, что и ПК. Открой адрес на телефоне, введи код. Код новый при каждом запуске,
после 5 неверных попыток вход блокируется на 5 минут. Порт в брандмауэре открывается
на время работы сайта и закрывается при остановке.
Отметки «просмотрено» и выбор релиза хранятся в каждом браузере отдельно.
Не работает с телефона: проверь, что сеть не «гостевая» и что адрес взят из окна PowerShell.
Из другой сети (мобильный интернет) нужен туннель, например Tailscale.

ССЫЛКА ДЛЯ ДРУЗЕЙ ИЗ ЛЮБОЙ СЕТИ
Запусти так:  powershell -ExecutionPolicy Bypass -File .\start.ps1 -Public
Скрипт сам скачает cloudflared (официальная программа Cloudflare, один раз, ~20 МБ, лежит в
папке tools) и выдаст ссылку вида https://что-то.trycloudflare.com/?t=... — она скопируется
в буфер обмена. Отправь её целиком. Открывается на любом устройстве без кода и без регистрации,
пока на твоём ПК открыто окно PowerShell. Ссылка новая при каждом запуске. Кто знает полную
ссылку — тот заходит, поэтому отправляй её только тем, кому доверяешь.
Можно совмещать: .\start.ps1 -Share -Public.
Антивирус иногда ругается на cloudflared; это официальный файл Cloudflare, но решать тебе.

СВОЙ ДОМЕН (постоянная ссылка)
Нужен домен, который ты купил (любой регистратор; Cloudflare продаёт по себестоимости),
добавленный в бесплатный аккаунт Cloudflare (смена серверов имён у регистратора).
1. Один раз:  powershell -ExecutionPolicy Bypass -File .\start.ps1 -Setup -Domain slime.твойдомен.com
   Откроется браузер: войди в Cloudflare, выбери домен, нажми Authorize.
   Скрипт создаст туннель, привяжет к нему адрес и сохранит настройки в site.config.json.
2. Дальше всегда:  powershell -ExecutionPolicy Bypass -File .\start.ps1 -Public
   Ссылка вида https://slime.твойдомен.com/?t=КЛЮЧ не меняется между запусками.
   Сменить ключ: удали site.config.json и снова выполни -Setup.

ЛИЧНЫЙ БЕСПЛАТНЫЙ АДРЕС (только твои устройства)
Через Tailscale (бесплатный личный тариф): адрес вида https://имя-пк.твоя-сеть.ts.net,
постоянный, с https, работает из любой сети и открывается ТОЛЬКО на устройствах,
где ты вошёл в свой Tailscale. Посторонние его не откроют.
1. Установи Tailscale на ПК и на телефон (tailscale.com/download), войди одним аккаунтом.
2. В админке Tailscale (login.tailscale.com/admin/dns) включи MagicDNS и HTTPS-сертификаты.
3. Запусти:  powershell -ExecutionPolicy Bypass -File .\start.ps1 -Tailscale
   (Windows спросит права администратора). Адрес появится в окне PowerShell.
4. На телефоне включи Tailscale и открой этот адрес. Имя ПК и сети можно поменять
   в админке Tailscale, чтобы адрес был покрасивее.
Другим людям этот адрес не откроется — не приглашай их в свой Tailscale.

БЕСПЛАТНАЯ ПОСТОЯННАЯ ССЫЛКА ДЛЯ ВСЕХ (Tailscale Funnel)
Адрес https://имя-пк.твоя-сеть.ts.net бесплатный и не меняется. Открывается у любого человека
на любом устройстве, кому ты отправил ссылку целиком (с ?t=КЛЮЧ), — Tailscale на их устройствах
не нужен. Работает, пока на твоём ПК открыто окно PowerShell.
1. Установи Tailscale на ПК (tailscale.com/download), войди в аккаунт.
2. В админке Tailscale (login.tailscale.com/admin/dns) включи MagicDNS и HTTPS-сертификаты.
3. Запусти:  powershell -ExecutionPolicy Bypass -File .\start.ps1 -Funnel
   Windows спросит права администратора. В первый раз Tailscale покажет ссылку, где нужно
   разрешить Funnel для этого ПК — открой её, нажми разрешить и запусти снова.
4. Ссылка со значением ?t=КЛЮЧ появится в окне и скопируется. Ключ сохраняется в
   site.config.json и не меняется. Сменить ключ: удали из этого файла строку accessKey.
Без ключа сайт не открывается. Отправляй ссылку тем, кому доверяешь.

Сайт живёт только пока работает окно PowerShell. Адрес защищён одноразовым ключом:
после остановки или без запуска через start.ps1 страница не откроется.

ПЛАГИНЫ
Каждый плагин — файл .js в www/plugins. Пример — plugins/_шаблон.js.txt.
Плагины никуда не переводят: серию всегда играет плеер самого сайта.
AniLibria: при первом запуске предложит выбрать релиз (для каждой части один раз),
дальше играет серии сам, с выбором качества 1080p/720p/480p. Сброс выбора —
раздел «Плагины», кнопка «Настроить». Ссылки на видео берутся из открытого API anilibria.top.

МОЙ ПЛЕЕР (кнопка «Мой плеер» в окне серии)
- «Папка с сериями»: выбери папку со скачанными сериями. Номер серии берётся из имени
  файла (S01E05, "- 05", ep05, "Серия 5"). Субтитры .srt/.vtt с тем же номером
  подхватываются сами. Выбирать папку нужно заново после перезагрузки страницы.
- «Файл серии» и «Субтитры»: выбрать вручную. .srt в Windows-1251 читается правильно.
- Ссылка: .mp4/.webm/.m3u8 играют встроенным плеером, любая другая страница
  открывается во фрейме. Ссылка запоминается для каждой серии.
- Место просмотра запоминается, после конца серии включается следующая (галочка «Автопереход»).
- Лучше всего работают mp4 и webm; mkv в браузере играет не всегда.

ДАННЫЕ
Описания и оценки — Shikimori (на русском), список серий и персонажи — Jikan.
Источники данных и их скрытые имена — в начале start.ps1 (переменная $Upstreams).
Если у Shikimori сменится домен, поменяй адреса b, c, d в $Upstreams в start.ps1.
Номера частей (SEASONS) — в начале www/app.js.
